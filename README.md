# 🌼 Aster

Aster is a personal life dashboard built in Python to help students and developers manage their daily life from one place.

It combines productivity, coding, academics, and fitness into a single desktop application that grows with its user.

> Currently in active development.

---

## ✨ Planned Features

### 💻 Coding
- GitHub commit tracking
- Coding timer
- Project tracker
- Daily coding goals

### 🎓 College
- Attendance tracker
- Timetable
- Assignment tracker
- Exam planner
- CGPA goals

### 💪 Fitness
- Workout log
- Weight tracker
- Gym progress

### ✅ Productivity
- To-do list
- Habit tracker
- Daily goals
- Notes
- Calendar
- Pomodoro timer

### 📊 Analytics
- Weekly reports
- Monthly reports
- Productivity insights

### 🤖 Future AI Integration
Aster is designed to eventually integrate **Luna**, an AI analytics assistant that provides personalized insights based on productivity, study, coding, and fitness data.

---

## 🚀 Project Status

Aster is currently in early development (Version 0.x).

The goal is to build the application incrementally throughout my engineering journey, focusing on clean architecture, maintainable code, and practical features.
