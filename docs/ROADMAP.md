# 🌼 Aster Roadmap

## Vision

Aster is a long-term desktop application designed to help students and developers manage their daily life from a single place.

The project is intended to grow gradually throughout its lifetime. Rather than attempting to build every feature at once, each version focuses on delivering a stable, meaningful improvement.

---

# Current Status

**Current Version:** Pre-Alpha (Development Started)

The project is currently focused on establishing a solid foundation before implementing user-facing features.

---

# Version Roadmap

### Goals

Build the core application framework.

### Planned Features

* Create the main application window.
* Design the navigation sidebar.
* Implement page switching.
* Establish the overall project architecture.
* Apply the initial application theme.

# Development Philosophy

Aster follows an iterative development approach.

Every version should improve the application while maintaining a clean architecture, readable code, and a stable user experience.

Features may move between versions as development priorities evolve.

This roadmap is a guide, not a strict contract.
